Sample Resolved Support Tickets

TICKET #SD-1042 | Priority: High (P2) Resolved & Verified

Issue: User Unable to Access Internal Intranet or Shared Drives (APIPA Address)

Symptoms: Workstation receiving 169.254.x.x IP address; user cannot reach file server or internet.

Troubleshooting Steps: Ran ipconfig /all confirming DHCP lease failure. Tested loopback (ping 127.0.0.1) to rule out NIC driver failure, verified virtual switch link state, flushed DNS, and ran ipconfig /release & ipconfig /renew after restarting the DHCP Client service.

Root Cause & Fix: Stale DHCP lease/client cache prevented renewal. Renewed valid IPv4 lease (10.10.10.45) and verified access to network shares.

TICKET #SD-1189 | Priority: Medium (P3) Resolved & Verified

Issue: Repeated Active Directory Account Lockouts After Password Change

Symptoms: User account locks out every 15 minutes despite entering the new password correctly.

Troubleshooting Steps: Verified user identity, unlocked account in Active Directory Users and Computers (ADUC), and checked Event Viewer Security Logs (Event ID 4740) on the Domain Controller to locate the caller workstation.

Root Cause & Fix: Cached credentials stored in Windows Credential Manager and a mobile mail client were retrying the old password. Cleared stale entries in Credential Manager and re-authenticated Outlook.

TICKET #SD-1264 | Priority: Medium (P3) Resolved & Verified

Issue: Network Print Queue Stuck on "Printing" Across Finance Department

Symptoms: Multiple users report print jobs hanging in queue with no output at the shared multifunction printer.

Troubleshooting Steps: Pinged printer static IP to confirm network reachability. Connected to print server, stopped the Print Spooler service, cleared corrupted .SPL and .SHD files from C:\Windows\System32\spool\PRINTERS, and restarted the spooler.

Root Cause & Fix: Corrupted print spool job blocked subsequent queue items. Printed test page and confirmed queue cleared.
