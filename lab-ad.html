Enterprise Active Directory Home Lab

End-to-end corporate domain simulation featuring AD DS, DNS, DHCP, Group Policy enforcement, and PowerShell user provisioning.

Lab Topology & VirtualBox Architecture

Built an isolated client-server enterprise network inside Oracle VM VirtualBox using an Internal Network adapter so DHCP/DNS services operate cleanly without conflicting with my home router.

Domain Controller (DC01)

OS: Windows Server 2022 Standard
Roles: AD DS, DNS Server, DHCP Server
Domain: corp.rochellelab.local (10.10.10.10/24)

Enterprise Workstation (CLIENT01)

Testing: GPO enforcement, mapped drives, logon scripts

Organizational Units (OUs) & Group Policy Objects

Structured Active Directory following Role-Based Access Control (RBAC) best practices:

  • OU Hierarchy: Created department OUs (IT_Support, HR, Finance, Operations) with dedicated security groups for NTFS folder permissions.
  • Password & Lockout Policy GPO: Enforced 12-character minimum password complexity and a 5-attempt account lockout threshold (15-minute lockout duration) to simulate real helpdesk lockout scenarios.
  • Mapped Network Drives GPO: Automatically mapped departmental shared folders (S:\Shared) upon domain user login.
  • Control Panel & USB Restrictions: Applied workstation hardening policies for standard domain user accounts.

PowerShell User Onboarding & Helpdesk Automation

Automated bulk Active Directory user creation and password resets using PowerShell:

New-ADBulkUsers.ps1 — PowerShell ISE (Administrator)
# Import new hire CSV and provision Active Directory accounts automatically
Import-Module ActiveDirectory
$Users = Import-Csv "C:\Scripts\NewHires.csv"

foreach ($User in $Users) {
    $SAM = ($User.FirstName.Substring(0,1) + $User.LastName).ToLower()
    $UPN = "$SAM@corp.rochellelab.local"
    $OU  = "OU=$($User.Department),DC=corp,DC=rochellelab,DC=local"

    New-ADUser -Name "$($User.FirstName) $($User.LastName)" `
               -SamAccountName $SAM `
               -UserPrincipalName $UPN `
               -Path $OU `
               -AccountPassword (ConvertTo-SecureString "TempPass2026!" -AsPlainText -Force) `
               -ChangePasswordAtLogon $true `
               -Enabled $true

    Add-ADGroupMember -Identity "GRP_$($User.Department)" -Members $SAM
    Write-Host "Provisioned: $UPN in $($User.Department)" -ForegroundColor Green
}
